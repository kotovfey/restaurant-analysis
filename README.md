Restaurant Data Analysis

1.  О проекте
В данном проекте проведён анализ данных о заказах в ресторане.

Цель — изучить поведение клиентов и выявить факторы, влияющие на размер счета и чаевых.

2. Используемые инструменты
- Python
- pandas
- matplotlib

3. Что было сделано
- Загружены и исследованы данные
- Посчитаны основные метрики (средний чек, чаевые)
- Выполнена группировка по:
  - полу
  - времени дня
  - размеру компании
- Добавлена новая метрика: счет на человека
- Построен график зависимости чека на человека от размера компании

4. Основные выводы
- Средний чек на человека снижается с увеличением размера компании
- Максимальный чек на человека наблюдается при размере компании 2 человека
- Существенной зависимости чаевых от пола не выявлено

5. Гипотеза
В больших компаниях клиенты чаще делят блюда и оптимизируют расходы,  
в то время как в небольших компаниях заказы более индивидуальны.
